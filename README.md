# Academic homepage

Simple static academic website for GitHub Pages.

## Files

- `index.html` — home page
- `research.html` — research
- `teaching.html` — teaching
- `cv.html` — CV
- `contact.html` — contact
- `style.css` — shared styling

To add a downloadable CV, place `cv.pdf` in the repository root.

Edit the text directly in the HTML files, commit the changes, and GitHub Pages will republish the site.
