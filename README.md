# Thingstad Group website

Static academic website for GitHub Pages.

## Files

- `index.html` — home page
- `research.html` — research
- `people.html` — people
- `teaching.html` — teaching
- `cv.html` — brief academic CV
- `join.html` — opportunities / join the group
- `contact.html` — contact
- `style.css` — shared styling
- `profile1.jpg` — profile photo

The e-mail address is assembled client-side with simple JavaScript on pages where it appears.

Edit the HTML/CSS files, commit the changes, and GitHub Pages will republish the site.


## Banner images

- `banner-home.png` — abstract group banner used on the Home page
- `banner-research.png` — abstract research banner used on the Research page


## Site-wide banner

- `banner-sitewide.png` — narrow scientific banner used below the navigation on all pages
